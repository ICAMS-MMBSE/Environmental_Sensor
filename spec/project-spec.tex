	\section{Summary}
	
	% One paragraph: what is being built and why.
	A Bluetooth Low Energy Mesh (SIG) is being built to monitor environmental data across the ICAMS shop floor. The data that will be collected includes temperature, humidity, CO2, sound level, O2, particulate matter, and volatile organic compounds. The sensors used are the SCD40, DFRobot Sound Level Meter V1.0 and 2.0, SEN54, and DFRobot Oxygen Sensor.
	
	The environmental sensors will be used to monitor working conditions and display on Grafana. Eventually, they will be connected to a ML algorithm to set thresholds that will trigger the smart switch system to power on and off dehumidifiers.
	
	\section{Background}
	
	% Current state and the problem this project addresses.
	This project will replace the previous system that was used to collect environmental sensor data through Bluetooth using the Arduino MKR Wifi 1010. This board was poorly suited for this task since Arduino does not have built-in support for BT SIG Mesh. Connections were limited to fewer than six nodes because of this, and data collection was spotty. Additionally, a new collector is being put in place and will run the script in a Docker container using Python, where all data will be pushed via MQTT through the broker Mosquitto.
